# Инструмент визуализации графа зависимостей пакетов

Программа представляет собой CLI-приложение для анализа и графического отображения дерева зависимостей пакетов. Все параметры конфигурации считываются из JSON-файла.

## Этап 1: Минимальный прототип с конфигурацией

Реализована инициализация приложения, валидация конфигурационного файла и обработка ошибок параметров.

### Настраиваемые параметры (config.json):
* `package_name` — Имя анализируемого пакета
* `repo_path` — Путь к тестовому репозиторию
* `mode` — Режим работы с репозиторием
* `output_image_path` — Путь к сгенерированному изображению графа
* `ascii_tree_path` — Путь к файлу вывода в формате ASCII-дерева

### Запуск проекта:
Выполнение осуществляется с помощью запускного файла:
```bash
run.bat
```
